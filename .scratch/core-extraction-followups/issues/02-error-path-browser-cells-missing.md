# 오류 경로 로그 문구·init 필터 오류 경로에 브라우저 확인 셀이 없다

Status: deferred
Origin: RD-020 L1·L2 결과. 브라우저에서 유도하는 셀이 없어 단위 시험만으로 확인된 3건이다.

## 현상

- 초기화 실패 시 콘솔 접두어가 `[repl.worker]`에서 `[worker]`로 바뀌었다. 문구를 유도하는 브라우저 셀이 없다(`repl-check`의 `콘솔 경고·오류가 없다` 셀은 오류가 없음만 본다).
- `stdin` 응답 실패 시 콘솔 문구가 `[repl] stdin 응답 실패`에서 `[session] stdin 응답 실패`로 바뀌었다. 유도하는 셀이 없다.
- worker init 수신이 `{ once: true }`에서 필터 리스너로 바뀌었다. 정상 경로는 L1·L2가 덮지만 배열 무시·`kind` 불일치 오류 경로는 단위 시험(`packages/pyodide-core/src/worker/run-worker.test.ts`)만 본다.

L1 4종·L2 499/499는 모두 통과했고 오류 경로가 깨졌다는 관찰은 없다. 코드 읽기와 단위 시험 기준의 미확인 항목이다.

## 재개 조건

거짓 결과가 관찰되면(오류 경로 문구·필터 수신이 브라우저에서 단위 시험과 다르게 동작) `open`으로 바꾼다. 또는 RD-022가 오류 상태 UI를 도입하면서 브라우저 오류 셀을 새로 쓸 때 함께 넣는다. 그 전에는 조사하지 않는다.
